# Каталог с предзаказом

Простой сайт-каталог: карточки товаров, фильтр по категориям, форма предзаказа, которая приходит на почту.

## Что где лежит

| Файл | Зачем |
|---|---|
| `config.js` | **Всё, что вы меняете:** название, тексты, товары, ID формы |
| `images/` | Фото товаров (положите сюда и укажите путь в `config.js`) |
| `index.html`, `styles.css`, `app.js` | Сам сайт, трогать не обязательно |

## Как добавить товар

Откройте `config.js`, скопируйте любой блок `{ ... },` в списке `PRODUCTS` и поменяйте поля.
Фото: положите `coat.jpg` в папку `images` и напишите `image: "images/coat.jpg"`.
Лучше всего смотрятся вертикальные фото 3:4 (например 900×1200).

## Как включить форму предзаказа

1. Зарегистрируйтесь на https://formspree.io (бесплатно, до 50 заявок в месяц).
2. Создайте форму (**New Form**), укажите почту, куда присылать заявки.
3. Formspree покажет адрес вида `https://formspree.io/f/xyzabcd`.
4. В `config.js` впишите последнюю часть: `formspreeId: "xyzabcd",`.

## Как посмотреть сайт

Откройте `index.html` двойным щелчком — он откроется в браузере.
