# Monaco KG Essentials — сайт предзаказа

Сайт на трёх языках (EN / RU / FR) по макетам «Monaco KG Essentials — макеты страниц».
Этап 1: страницы для покупателей. Заявки приходят на почту через Formspree.
Этап 2 (позже): база данных и админка (предзаказы, CRM, таблица спроса).

## Страницы

| Адрес | Страница |
|---|---|
| `#/en` | Главная |
| `#/en/shop` | Каталог (фильтры по категории, цвету, размеру, сортировка) |
| `#/en/product/<id>` | Товар + окно предзаказа |
| `#/en/thanks` | Спасибо за предзаказ |
| `#/en/about` | О бренде |
| `#/en/how` | Как работает предзаказ + FAQ |
| `#/en/contact` | Контакты + форма |
| `#/en/size` | Таблица размеров (см / дюймы) |
| `#/en/legal/privacy`, `terms`, `cookies` | Политики |
| всё остальное | 404 |

`en` можно заменить на `ru` или `fr`. При первом заходе язык берётся из браузера,
а если он не совпадает со страницей, сверху появляется подсказка «Переключить?».

## Что где менять

| Файл | Что внутри |
|---|---|
| `config.js` | Название, контакты, ID формы, **товары**, цвета, таблица размеров, фото первого экрана |
| `i18n.js` | **Все тексты** сайта на трёх языках |
| `images/` | Фото (укажите путь в `config.js`, например `images/hoodie-1.jpg`) |
| `index.html`, `app.js`, `styles.css` | Сам сайт, трогать не обязательно |

Всё в квадратных скобках `[ ... ]` — места, которые нужно заполнить.

## Как добавить товар

Скопируйте блок `{ id: ..., ... },` в `PRODUCTS` в `config.js` и поменяйте поля.
`id` — латиницей без пробелов, он становится адресом страницы товара.
Фото: вертикальные 3:4 (например 1200×1600). Первое показывается в каталоге, второе при наведении.

## Как включить формы (предзаказ и контакты)

1. Зарегистрируйтесь на https://formspree.io (бесплатно, 50 заявок в месяц).
2. **New Form** → укажите почту, куда присылать заявки.
3. Formspree покажет адрес вида `https://formspree.io/f/xyzabcd`.
4. В `config.js`: `formspreeId: "xyzabcd",`.

Каждая заявка придёт письмом: товар, цвет, размер, количество, контакты, адрес, язык и номер предзаказа `MKG-…`.
